# Manifiesto ético — AgriSmart API

El desarrollo de AgriSmart debe proteger tanto la información como los procesos físicos asociados al riego. El equipo se compromete a aplicar mínimo privilegio, validar entradas, proteger secretos, mantener trazabilidad, corregir vulnerabilidades conocidas y ejecutar pruebas únicamente en entornos autorizados. La seguridad se considera un requisito del sistema desde el diseño y no una característica opcional.
