# Organization Normative Framework (ONF) — AgriSmart

## Contexto
AgriSmart recibe telemetría agrícola y controla zonas de riego.

## Propiedades prioritarias
- Confidencialidad: datos visibles solo por usuarios autorizados.
- Integridad: impedir cambios no autorizados en sensores, umbrales y riego.
- Disponibilidad: mantener funciones de monitoreo y control disponibles.

## Referencias
- ISO/IEC 27034 para seguridad de aplicaciones.
- OWASP Top 10:2021 para clasificación de riesgos.
- Legislación chilena aplicable al tratamiento de datos e incidentes, según el contexto real de la organización.

## Roles
- Desarrollador
- Responsable de seguridad
- Administrador
- Agricultor/usuario
- Auditor
